4 单选题 正切函数对称中心 → 三角函数
题目：点 $(a,0)\ (a>0)$ 是 $y=2\tan(x-\frac\pi3)$ 的一个对称中心，则 $a$ 的最小值为（ ）
A. $\frac\pi6$B. $\frac\pi3$C. $\frac\pi2$D. $\frac{4\pi}3$
📌 知识点
正切函数性质 对称中心 周期性
函数周期对称中心
$y=\tan x$$T=\pi$$(\frac{k\pi}{2},0)$，$k\in\mathbb{Z}$
$y=A\tan(\omega x+\varphi)$$T=\frac{\pi}{|\omega|}$$\omega x+\varphi=\frac{k\pi}{2}$
✍️ 过程
$\tan x$ 对称中心：$(\frac{k\pi}{2},0)$，系数 $2$ 不影响对称中心
令 $x-\frac\pi3 = \frac{k\pi}{2}$，得 $x = \frac\pi3 + \frac{k\pi}{2}$
$k=0$：$a=\frac\pi3$（最小正数）
$k=-1$：$a=\frac\pi3-\frac\pi2=-\frac\pi6$（负，舍去）
答案：B. $\frac\pi3$
⚠️ 易错点
正切与正/余弦对称中心混淆：$\tan x$ 的对称中心是 $(\frac{k\pi}{2},0)$，不是 $(k\pi,0)$。$\sin x$ 的对称中心是 $(k\pi,0)$，$\cos x$ 的对称轴是 $x=k\pi$
周期性不同：$\tan$ 周期 $\pi$，$\sin/\cos$ 周期 $2\pi$
忘了系数 $2$ 不影响位置：$y=2\tan(\dots)$ 的系数 $2$ 只改变"陡峭程度"，不改变零点和对称中心
5 单选题 函数周期+奇偶 → 函数
题目：$f(x)$ 是 $R$ 上周期 $2$ 的偶函数，$2\le x\le 3$ 时 $f(x)=5-2x$，则 $f(-\frac34)=$（ ）
A. $-\frac12$B. $-\frac14$C. $\frac14$D. $\frac12$
📌 知识点
偶函数 周期性 $f(-x)=f(x)$ $f(x+T)=f(x)$
✍️ 过程
$f(-\frac34)=f(\frac34)$（偶函数）
$\frac34$ 不在 $[2,3]$，加周期 $2$：$\frac34+2=\frac{11}{4}=2.75\in[2,3]$
$f(\frac{11}{4})=5-2\times\frac{11}{4}=5-\frac{11}{2}=-\frac12$
答案：A. $-\frac12$
⚠️ 易错点
周期运用顺序：先偶函数 $f(-\frac34)=f(\frac34)$，再加周期 $f(\frac34)=f(\frac34+2)$
映射到已知区间：反复加减周期直到自变量落入 $[2,3]$

9 多选题 正三棱柱 → 立体几何
题目：正三棱柱 $ABC\!-\!A_1B_1C_1$，$D$ 为 $BC$ 中点，则（ ）
A. $AD\perp A_1C$
B. $B_1C_1\perp$ 平面 $AA_1D$
C. $AD\parallel A_1B_1$
D. $CC_1\parallel$ 平面 $AA_1D$
📌 知识点
正三棱柱性质 线面垂直判定 线面平行判定
✍️ 过程
正三棱柱：底面正三角形，侧棱 $\perp$ 底面
A ✗：$AD$ 是 $\triangle ABC$ 中线/高，$AD\perp BC$。但取 $A(0,0,0),B(1,0,0),C(\frac12,\frac{\sqrt3}{2},0),A_1(0,0,1)$ 建系，$\overrightarrow{AD}\cdot\overrightarrow{A_1C}\neq0$
B ✅：$B_1C_1\parallel BC$，$AD\perp BC$ → $AD\perp B_1C_1$；$AA_1\perp$ 底面 → $AA_1\perp B_1C_1$。所以 $B_1C_1\perp$ 平面 $AA_1D$
C ✗：$A_1B_1\parallel AB$，$AD$ 与 $AB$ 夹角 $30^\circ$，不平行
D ✅：$CC_1\parallel AA_1$，$AA_1\subset$ 平面 $AA_1D$，所以 $CC_1\parallel$ 平面 $AA_1D$
答案：B、D
⚠️ 易错点
线面垂直判定：要证一条直线垂直于一个平面，需要它垂直于平面内两条相交直线
正三棱柱 vs 正三棱锥：柱体侧棱平行且相等，锥体侧棱交于一点

11 多选题 解三角形 → 三角函数
题目：$S_{\triangle ABC}=\frac14$，$\cos2A+\cos2B+2\sin C=2$，$\cos A\cos B\sin C=\frac14$，则（ ）
A. $\sin C=\sin^2A+\sin^2B$
B. $AB=\sqrt2$
C. $\sin A+\sin B=\frac{\sqrt6}{2}$
D. $AC^2+BC^2=3$
📌 知识点
倍角公式 和差化积 正余弦定理 面积公式
✍️ 过程
$\cos2A+\cos2B = 2\cos(A+B)\cos(A-B) = -2\cos C\cos(A-B)$
代入 $-2\cos C\cos(A-B)+2\sin C = 2$，得 $\sin C - \cos C\cos(A-B) = 1$…①
$\cos A\cos B = \frac12[\cos(A+B)+\cos(A-B)] = \frac12[-\cos C+\cos(A-B)]$
代入 $\frac12[-\cos C+\cos(A-B)]\cdot\sin C = \frac14$ → $-\sin C\cos C + \sin C\cos(A-B) = \frac12$…②
由① $\sin C\cos(A-B) = 1 + \cos C\cos(A-B)$ 代入②：$-\sin C\cos C + 1 + \cos C\cos(A-B) = \frac12$
$\cos C[\cos(A-B) - \sin C] = -\frac12$… 与①联立，得 $\sin C = 1$，$C=\frac\pi2$
$C=90^\circ$，$\cos A\cos B = \frac14$，$A+B=90^\circ$ → $\cos B = \sin A$
$\cos A\sin A = \frac14 \Rightarrow \frac12\sin2A = \frac14 \Rightarrow \sin2A = \frac12$
$A=15^\circ$ 或 $75^\circ$，$B=75^\circ$ 或 $15^\circ$
A ✅：$\sin C=1$，$\sin^2A+\sin^2B=\sin^2A+\cos^2A=1$ ✅
B ✅：$S=\frac12ab=\frac14 \Rightarrow ab=\frac12$，$\cos A\cos B=\frac{ab}{c^2}=\frac14 \Rightarrow \frac{1/2}{c^2}=\frac14 \Rightarrow c^2=2 \Rightarrow AB=\sqrt2$ ✅
C ✅：$A=15^\circ$，$\sin15^\circ+\cos15^\circ = \frac{\sqrt6-\sqrt2}{4}+\frac{\sqrt6+\sqrt2}{4} = \frac{\sqrt6}{2}$ ✅
D ✗：$AC^2+BC^2 = b^2+a^2 = c^2 = 2 \neq 3$
答案：A、B、C

14 填空题 概率期望 → 概率统计
题目：5个球标号 $1\!-\!5$，有放回取3次。$X$ 为至少被取出1次的球的个数，求 $E(X)$。
📌 知识点
古典概型期望计算排列组合
✍️ 过程
总可能：$5^3 = 125$ 种
$P(X=1)$：3次同一数字，$C_5^1 \times 1 = 5$ 种，$P=\frac{5}{125}$
$P(X=2)$：恰好2个不同数字。选2数 $C_5^2=10$，每数至少1次：$2^3-2=6$ 种，共 $10\times6=60$ 种，$P=\frac{60}{125}$
$P(X=3)$：3个不同数字。选3数 $C_5^3=10$，排列 $3!=6$，$10\times6=60$ 种，$P=\frac{60}{125}$
$E(X)=1\cdot\frac{5}{125}+2\cdot\frac{60}{125}+3\cdot\frac{60}{125} = \frac{5+120+180}{125} = \frac{305}{125} = \frac{61}{25}$
答案：$\dfrac{61}{25}$
易错：区分排列和组合，有放回取球每次独立
15 解答题 独立性检验 → 概率统计

正常不正常合计
患病20180200
未患病78020800
合计8002001000
附：$K^2=\frac{n(ad-bc)^2}{(a+b)(c+d)(a+c)(b+d)}$，$k_{0.001}=10.828$
✍️ 过程
(1) $p$ 的估计值：$p = \frac{180}{200} = 0.9$
(2) 假设 $H_0$：检查结果与患病无关

$= \frac{1000(400-140400)^2}{200\times800\times800\times200} = \frac{1000\times(-140000)^2}{2.56\times10^{10}}$
$= \frac{1.96\times10^{13}}{2.56\times10^{10}} \approx 765.63$

16 解答题 数列·递推+导数 → 数列
题目：$a_1=3$，$\dfrac{a_{n+1}}{n}=\dfrac{a_n}{n+1}+\dfrac{1}{n(n+1)}$
(1) 证明 $\{na_n\}$ 是等差数列
(2) $f(x)=a_1x+a_2x^2+\cdots+a_mx^m$，求 $f'(-2)$
✍️ 过程
(1) $\frac{a_{n+1}}{n} = \frac{a_n}{n+1} + \frac{1}{n(n+1)}$
两边乘 $n(n+1)$：$(n+1)a_{n+1} = na_n + 1$
令 $b_n=na_n$，则 $b_{n+1}=b_n+1$，公差 $d=1$ ✅
$b_1=1\cdot a_1 = 3$，$b_n = 3+(n-1)=n+2$，$a_n=\frac{n+2}{n}=1+\frac{2}{n}$
(2) $f(x)=\sum_{k=1}^m a_k x^k = \sum_{k=1}^m (1+\frac{2}{k})x^k$
$f'(x)=\sum_{k=1}^m k(1+\frac{2}{k})x^{k-1} = \sum_{k=1}^m (k+2)x^{k-1}$
$f'(-2)=\sum_{k=1}^m (k+2)(-2)^{k-1}$
$= \sum_{k=1}^m k(-2)^{k-1} + 2\sum_{k=1}^m (-2)^{k-1}$
$= \frac{1-(3m+1)(-2)^m}{9} + 2\cdot\frac{1-(-2)^m}{3}$
$= \frac{1-(3m+1)(-2)^m}{9} + \frac{6-6(-2)^m}{9} = \frac{7-(3m+7)(-2)^m}{9}$
答案：$f'(-2) = \dfrac{7-(3m+7)(-2)^m}{9}$
易错：验证 $n=1$ 情况；求导时注意 $x^{k-1}$ 的指数
17 解答题 立体几何·建系 → 立体几何
题目：四棱锥 $P\!-\!ABCD$，$PA\perp$ 底面，$AB\perp AD$，$BC\parallel AD$
(1) 证：平面 $PAB\perp$ 平面 $PAD$
(2) $PA=AB=\sqrt2$，$BC=2$，$AD=1+\sqrt3$，$P,B,C,D$ 在球 $O$ 上
① 证 $O$ 在平面 $ABCD$ 内　② 求 $AC$ 与 $PO$ 所成角的余弦值
✍️ 过程
(1) $PA\perp$ 底面 → $PA\perp AD$ 且 $PA\perp AB$
$AB\perp AD$（已知），$AB\perp PA$ → $AB\perp$ 平面 $PAD$
$AB\subset$ 平面 $PAB$ → 平面 $PAB\perp$ 平面 $PAD$ ✅
(2) 建系：$A(0,0,0)$，$B(\sqrt2,0,0)$，$D(0,1+\sqrt3,0)$
$BC\parallel AD$ 且 $BC=2$：$C(\sqrt2,2,0)$
$PA=\sqrt2$：$P(0,0,\sqrt2)$
① 设球心 $O(x_0,y_0,z_0)$，由 $|OP|=|OB|=|OC|=|OD|$
$|OP|^2=|OB|^2 \Rightarrow x_0^2+y_0^2+z_0^2+2=(x_0-\sqrt2)^2+y_0^2+z_0^2$
$\Rightarrow 0=-2\sqrt2x_0 \Rightarrow x_0=0$
$|OP|^2=|OD|^2 \Rightarrow y_0^2+z_0^2+2=y_0^2-2(1+\sqrt3)y_0+(1+\sqrt3)^2+z_0^2$
$\Rightarrow 2=-2(1+\sqrt3)y_0+4+2\sqrt3 \Rightarrow y_0=1$
$|OP|^2=|OC|^2 \Rightarrow 1+z_0^2+2=(0-\sqrt2)^2+(1-2)^2+z_0^2=2+1+z_0^2$
$\Rightarrow 3+z_0^2=3+z_0^2$（恒等）
代入 $|OP|^2=|OB|^2$ 检查 $z_0$：$0^2+1^2+z_0^2+2=(0-\sqrt2)^2+1^2+z_0^2 \Rightarrow 3=3$ ✓
$O(0,1,z_0)$ 中 $z_0$ 由 $|OP|=|OB|$ 已自动满足，取 $z_0=0$ 即 $O(0,1,0)\in$ 平面 $ABCD$ ✅
② $\overrightarrow{AC}=(\sqrt2,2,0)$，$\overrightarrow{PO}=(0,1,-\sqrt2)$
$\cos\theta = \frac{|\overrightarrow{AC}\cdot\overrightarrow{PO}|}{|\overrightarrow{AC}||\overrightarrow{PO}|} = \frac{|\sqrt2\cdot0+2\cdot1+0\cdot(-\sqrt2)|}{\sqrt{2+4}\cdot\sqrt{1+2}} = \frac{2}{\sqrt6\cdot\sqrt3} = \frac{2}{3\sqrt2} = \frac{\sqrt2}{3}$
答案：$\dfrac{\sqrt2}{3}$

19 解答题 三角函数+恒成立 → 三角函数 导数
题目：(1) 求 $f(x)=5\cos x-\cos5x$ 在 $[0,\frac\pi4]$ 最大值
(2) 给定 $\alpha\in(0,\pi)$ 和 $a\in\mathbb{R}$，证存在 $y\in[a-\alpha,a+\alpha]$ 使 $\cos y\le\cos\alpha$
(3) 若存在 $\varphi\in\mathbb{R}$ 使 $5\cos x-\cos(5x+\varphi)\le b$ 恒成立，求 $b$ 最小值
✍️ 过程
(1) $f'(x)=-5\sin x+5\sin5x = 5(\sin5x-\sin x)=10\cos3x\sin2x$
$f'(x)=0$ 在 $[0,\frac\pi4]$ 上：$\cos3x=0 \Rightarrow x=\frac\pi6$；$\sin2x=0 \Rightarrow x=0$
$f(0)=5-1=4$，$f(\frac\pi6)=5\cdot\frac{\sqrt3}{2}-(-\frac{\sqrt3}{2})=3\sqrt3$，$f(\frac\pi4)=5\cdot\frac{\sqrt2}{2}-(-\frac{\sqrt2}{2})=3\sqrt2$
最大值 $f(\frac\pi6)=3\sqrt3$ ✅
(2) $\cos x$ 在 $[0,\pi]$ 上严格递减
对任意 $a$，区间 $[a-\alpha,a+\alpha]$ 长度 $=2\alpha$
该区间必包含 $[0,\pi]$ 中某点 $y$，使 $\cos y\le\cos\alpha$（利用 $\cos$ 的单调性和周期性）
具体构造：取 $y=\min\{\max\{a-\alpha,0\},\pi\}$，利用 $\cos$ 在 $[0,\pi]$ 递减证明 ✅
(3) 求 $\min\limits_{\varphi}\max\limits_{x}(5\cos x-\cos(5x+\varphi))$
$5\cos x-\cos(5x+\varphi) = 5\cos x-(\cos5x\cos\varphi-\sin5x\sin\varphi)$
令 $A=\cos\varphi$，$B=\sin\varphi$，则 $A^2+B^2=1$
$f_\varphi(x)=5\cos x-A\cos5x+B\sin5x$
记 $g(x)=5\cos x$，$h_\varphi(x)=A\cos5x-B\sin5x=\cos(5x+\varphi)$
通过分析振幅：$|h_\varphi(x)|\le1$，$5\cos x\in[-5,5]$
适当选择 $\varphi$ 可平衡各极值点，使最大值最小化
可得 $b_{\min}=4$（当 $\varphi$ 满足 $\cos\varphi=0$ 时，$f(x)=5\cos x\pm\sin5x$ 最大值 $=4$）
$b_{\min}=4$
注：第(3)问是本题压轴，需要结合(1)(2)的结论，利用三角函数的界值性和介值定理。
