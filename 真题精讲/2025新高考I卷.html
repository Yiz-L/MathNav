1 单选题 复数运算 考点速查 → 复数
题目：$(1+5i)i$ 的虚部为（ ）
A. $-1$ B. $0$ C. $1$ D. $6$
📌 知识点
复数乘法 $i^2 = -1$ 虚部定义
考点内容
复数乘法$(a+bi)(c+di) = ac + adi + bci + bdi^2$，按多项式乘法展开
虚数单位$i^2 = -1$
虚部定义$a+bi$ 的虚部是 $b$（不含 $i$），实部是 $a$
✍️ 解题过程
展开：$(1+5i)i = 1\cdot i + 5i \cdot i = i + 5i^2$
代入 $i^2 = -1$：$i + 5(-1) = i - 5 = -5 + i$
标准形式 $-5 + 1\cdot i$，虚部为 $1$
答案：C. $1$
⚠️ 教学易错点
虚部定义混淆：学生答 $-5+i$（整个复数）或说虚部是 $i$。正确：虚部是 $i$ 前面的系数，即 $1$
$i^2$ 记错：$i^2 = -1$（不是 $1$ 也不是 $i$）
格式混乱：算完 $i-5$ 后要写成 $a+bi$ 形式再判断
2 单选题 集合运算 考点速查 → 集合
题目：已知集合 $U = \{x \mid x \text{ 是小于 9 的正整数}\}$，$A = \{1, 3, 5\}$，则 $\complement_{U} A$ 中元素的个数为（ ）
A. $0$ B. $3$ C. $5$ D. $8$
📌 知识点
集合表示法 补集运算 正整数集
✍️ 解题过程
$U = \{1, 2, 3, 4, 5, 6, 7, 8\}$（小于9的正整数，共8个）
$A = \{1, 3, 5\}$
$\complement_{U} A = U \setminus A = \{2, 4, 6, 7, 8\}$
元素个数为 $5$
答案：C. $5$
⚠️ 教学易错点
"小于9"不含9：正整数 $U = 1\text{-}8$，不是 $1\text{-}9$
问的是"个数"不是集合本身：要答数字 $5$，不是 $\{2,4,6,7,8\}$
3 单选题 双曲线离心率 考点速查 → ⚠️ 薄弱点
题目：已知双曲线 $C$ 的虚轴长是实轴长的 $\sqrt{7}$ 倍，则 $C$ 的离心率为（ ）
A. $\sqrt{2}$ B. $2$ C. $\sqrt{7}$ D. $2\sqrt{2}$
📌 知识点
双曲线 离心率 $e = c/a$ $c^2 = a^2 + b^2$ 实轴 $2a$ · 虚轴 $2b$
✍️ 解题过程
虚轴长 $2b$ 是实轴长 $2a$ 的 $\sqrt{7}$ 倍：$2b = \sqrt{7}\cdot 2a \Rightarrow b = \sqrt{7}a$
双曲线 $c^2 = a^2 + b^2$：$c^2 = a^2 + (\sqrt{7}a)^2 = a^2 + 7a^2 = 8a^2$
$c = \sqrt{8}a = 2\sqrt{2}a$
$e = \dfrac{c}{a} = \dfrac{2\sqrt{2}a}{a} = 2\sqrt{2}$
答案：D. $2\sqrt{2}$
⚠️ 教学易错点
🔴 椭圆与双曲线公式混淆（最高频错误）： 椭圆 $c^2 = a^2 - b^2$，双曲线 $c^2 = a^2 + b^2$。一字之差，天壤之别。 详情 → 考点速查·薄弱点详情
实轴/虚轴是 $2a$/$2b$：问"长"要记得乘 2，$a$ 和 $b$ 是半轴长
离心率范围检验：双曲线 $e>1$，算出 $e<1$ 立刻知道算错了
