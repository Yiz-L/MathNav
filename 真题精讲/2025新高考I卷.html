4 单选题 正切函数对称中心 → 三角函数
题目：点 $(a,0)\ (a>0)$ 是 $y=2\tan(x-\frac\pi3)$ 的一个对称中心，则 $a$ 的最小值为（ ）
A. $\frac\pi6$B. $\frac\pi3$C. $\frac\pi2$D. $\frac{4\pi}3$
📌 知识点
正切函数性质 对称中心 周期性
🔴 红点：$y=\tan x$ 的对称中心 $(\frac{k\pi}{2},0)$，每 $\frac\pi2$ 出现一次
函数周期对称轴对称中心渐近线
$y=\sin x$ $2\pi$ $x = \frac\pi2 + k\pi$ $(k\pi, 0)$ 无
$y=\cos x$ $2\pi$ $x = k\pi$ $(\frac\pi2 + k\pi, 0)$ 无
$y=\tan x$ $\pi$ 无 $(\frac{k\pi}{2}, 0)$ $x = \frac\pi2 + k\pi$
💡 记忆口诀：$\sin$ 中 $\cos$ 轴，$\cos$ 中 $\sin$ 轴；$\tan$ 每隔 $\frac\pi2$ 就对称。
即 $\sin x$ 的对称中心在 $\cos x$ 的零点处，反之亦然；$\tan x$ 对称中心间隔 $\frac\pi2$。
🌟 常考对称中心值（$y=\tan x$）
$k=-2$$(-\pi,0)$$k=0$$(0,0)$
$k=-1$$(-\frac\pi2,0)$$k=1$$(\frac\pi2,0)$
💡 间隔是 $\frac\pi2$，不是 $\pi$！$(\pi,0)$ 也是对称中心（$k=2$）
✍️ 过程
Step 1 · 对称中心公式
$y=\tan x$ 的对称中心：$(\frac{k\pi}{2},0),\ k\in\mathbb{Z}$（间隔 $\frac\pi2$）
$y=A\tan(\omega x+\varphi)$ 的对称中心：$\omega x+\varphi = \frac{k\pi}{2}$
系数 $A=2$ 只改变"陡峭程度"，不影响对称中心的位置。
Step 2 · 代入解 $x$
令 $x-\frac\pi3 = \frac{k\pi}{2}$ $\Rightarrow x = \frac\pi3 + \frac{k\pi}{2}$
Step 3 · 找最小正数 $a$
$k=0$：$a=\frac\pi3 \approx 1.05$ ✅ （正数且最小）
$k=-1$：$a=\frac\pi3-\frac\pi2 = -\frac\pi6 < 0$ ❌ （舍去）
答案：B. $\frac\pi3$
⚠️ 易错点
正切对称中心公式记错：$\tan x$ 的对称中心是 $(\frac{k\pi}{2},0)$（每 $\frac\pi2$ 一个），不是 $(k\pi,0)$（那是 $\sin x$ 的对称中心）。两者正好差一倍间隔，最容易混淆！
$\tan$ 的对称轴 vs 对称中心：$\tan x$ 没有对称轴，但有渐近线 $x=\frac\pi2+k\pi$。渐近线位置不是对称中心，别搞混。
平移方向记反：$x-\frac\pi3$ 是向右平移 $\frac\pi3$，对称中心随之右移。如果是 $x+\frac\pi3$ 则向左移。
5 单选题 函数周期+奇偶 → 函数
题目：$f(x)$ 是 $R$ 上周期 $2$ 的偶函数，$2\le x\le 3$ 时 $f(x)=5-2x$，则 $f(-\frac34)=$（ ）
A. $-\frac12$B. $-\frac14$C. $\frac14$D. $\frac12$
📌 知识点
偶函数 周期性 易丢分
已知区间 → 目标值 → 两步跳跃：偶函数对称 → 加周期落入已知区间
周期函数解题模板
步骤操作本题示例
1 · 奇偶性处理 负自变量 → 正自变量
偶: f(-x)=f(x) / 奇: f(-x)=-f(x)		 f(-3/4) = f(3/4)
2 · 周期性跳跃 反复加/减周期 T 直到 x 在已知区间内 3/4 + 2 = 11/4 ∈ [2,3]
3 · 代入求值 用已知区间表达式计算 f(11/4)=5-2×11/4=-1/2
周期性·高频失分点
  • 先奇偶再周期 — 永远先处理 f(-x)，再处理 f(x+T)。顺序反了会多跳一次。
  • 周期方向 — 自变量偏小就加周期，偏大就减周期，直到落入已知区间
  • 循环落点检查 — 跳完后确认新 x 在已知区间内，否则继续跳
  • 半周期陷阱 — f(x+T/2) 不能简化为 f(x)，周期只保证 f(x+T)=f(x)
奇偶性 + 周期性 联合速查
性质公式图像特征作用
偶函数f(-x)=f(x)关于 y 轴对称负转正
奇函数f(-x)=-f(x)关于原点对称负转正并取反
周期 Tf(x+T)=f(x)每隔 T 重复任意自变量→已知区间
偶+周期 f(a) = f(|a|) = f(|a|+T) = f(|a|+2T) = ... 直到落入已知区间
✍️ 过程
$f(-\frac34)=f(\frac34)$（偶函数）
$\frac34$ 不在 $[2,3]$，加周期 $2$：$\frac34+2=\frac{11}{4}=2.75\in[2,3]$
$f(\frac{11}{4})=5-2\times\frac{11}{4}=5-\frac{11}{2}=-\frac12$
答案：A. $-\frac12$
⚠️ 易错点
周期运用顺序：先偶函数 $f(-\frac34)=f(\frac34)$，再加周期 $f(\frac34)=f(\frac34+2)$
映射到已知区间：反复加减周期直到自变量落入 $[2,3]$
6 单选题 向量·风速合成 → 平面向量
题目：帆船比赛中，运动员可借助风力计测定风速的大小与方向，测出的结果在航海学中称为视风风速。视风风速对应的向量是真风风速对应的向量与船行风风速对应的向量之和，其中船行风风速对应的向量与船速对应的向量大小相等、方向相反。图1给出了部分风力等级、名称与风速大小的对应关系。已知某帆船运动员在某时刻测得的视风风速对应的向量与船速对应的向量如图2所示（线段长度代表速度大小，单位：m/s），则该时刻的真风为（ ）
A. 轻风B. 微风C. 和风D. 劲风
📌 知识点
向量加法 向量减法 向量坐标表示 向量模长
运算几何操作坐标公式口诀
加法 a+b a 尾接 b 头，封闭边即和 (x1+x2, y1+y2) 首尾相连，和封闭
减法 a-b 化为加法：a+(-b) (x1-x2, y1-y2) 减变加，反向再首尾
反向 -a 大小不变，方向相反 (-x1, -y1) 分量变号
模长 |a| 向量长度 sqrt(x^2+y^2) 勾股定理
量物理意义关系式
真风 v_true海面实际风速（待求）—
视风 v_app船上测得的实际风速v_app = v_true + v_wind
船行风 v_wind船行产生的相对风
船速 v_boat帆船航行速度v_wind = -v_boat
向量加减易错警示
  • 减法的本质是加法：a - b = a + (-b)。图中两向量首尾相接时，直接首起点到尾终点就是和向量。
  • 方向相反：船行风与船速大小相等、方向相反，即 v_wind = -v_boat。代入时注意变号。
  • 不要凭感觉"减"：从 v_app = v_true + v_wind 推导真风时，v_true = v_app - v_wind = v_app + v_boat。
  • 模长不是分量相加：(4,4) 的模长是 sqrt(16+16)=4sqrt2，不是 4+4=8
✍️ 解题过程
Step 1 · 建立向量关系
由题：$\vec{v}_{\text{视风}} = \vec{v}_{\text{真风}} + \vec{v}_{\text{船行风}}$，且 $\vec{v}_{\text{船行风}} = -\vec{v}_{\text{船速}}$
$\therefore \vec{v}_{\text{真风}} = \vec{v}_{\text{视风}} - \vec{v}_{\text{船行风}} = \vec{v}_{\text{视风}} + \vec{v}_{\text{船速}}$
Step 2 · 从图2读取向量分量
图中两向量首尾相连： $\vec{v}_{\text{船速}}$ 起点 $(2,0)$ → 终点 $(3,3)$，分量 $(1,3)$ ； $\vec{v}_{\text{视风}}$ 起点 $(3,3)$ → 终点 $(0,2)$，分量 $(-3,-1)$ 。
Step 3 · 向量加法求真风
$\vec{v}_{\text{真风}} = \vec{v}_{\text{视风}} + \vec{v}_{\text{船速}} = (1,3) + (-3,-1) = (-2,2)$
Step 4 · 计算模长
$|\vec{v}_{\text{真风}}| = \sqrt{(-2)^2 + 2^2} = \sqrt{8} = 2\sqrt2 \approx 2.83\ \mathrm{m/s}$
Step 5 · 对照风级表
$1.6\ \mathrm{m/s} < 2.83 < 3.3\ \mathrm{m/s}$，对应图1中的 2级 轻风。
答案：A. 轻风
⚠️ 易错点
方向关系混淆：$\vec{v}_{\text{船行风}} = -\vec{v}_{\text{船速}}$， 代入 $\vec{v}_{\text{视风}} = \vec{v}_{\text{真风}} + \vec{v}_{\text{船行风}}$ 得 $\vec{v}_{\text{真风}} = \vec{v}_{\text{视风}} + \vec{v}_{\text{船速}}$，不是相减。
向量加法图形：图中两向量首尾相接（船速终点=视风起点）， 因此船速与视风的"和"即从船速起点指向视风终点的向量 $(-2,2)$。
查表区间：$2.83$ 落在 $1.6\sim3.3$ 对应 2级轻风， 不是 3级微风（$3.4\sim5.4$）。

$1202 ✅

9 多选题 正三棱柱 → 立体几何
题目：正三棱柱 $ABC\!-\!A_1B_1C_1$，$D$ 为 $BC$ 中点，则（ ）
A. $AD\perp A_1C$
B. $B_1C_1\perp$ 平面 $AA_1D$
C. $AD\parallel A_1B_1$
D. $CC_1\parallel$ 平面 $AA_1D$
📌 知识点
正三棱柱性质 线面垂直判定 线面平行判定
✍️ 过程
正三棱柱：底面正三角形，侧棱 $\perp$ 底面
A ✗：$AD$ 是 $\triangle ABC$ 中线/高，$AD\perp BC$。但取 $A(0,0,0),B(1,0,0),C(\frac12,\frac{\sqrt3}{2},0),A_1(0,0,1)$ 建系，$\overrightarrow{AD}\cdot\overrightarrow{A_1C}\neq0$
B ✅：$B_1C_1\parallel BC$，$AD\perp BC$ → $AD\perp B_1C_1$；$AA_1\perp$ 底面 → $AA_1\perp B_1C_1$。所以 $B_1C_1\perp$ 平面 $AA_1D$
C ✗：$A_1B_1\parallel AB$，$AD$ 与 $AB$ 夹角 $30^\circ$，不平行
D ✅：$CC_1\parallel AA_1$，$AA_1\subset$ 平面 $AA_1D$，所以 $CC_1\parallel$ 平面 $AA_1D$
答案：B、D
⚠️ 易错点
线面垂直判定：要证一条直线垂直于一个平面，需要它垂直于平面内两条相交直线
正三棱柱 vs 正三棱锥：柱体侧棱平行且相等，锥体侧棱交于一点
10 多选题 抛物线综合 → 解析几何
题目：$C:y^2=6x$，$F$ 为焦点，$AB$ 过 $F$，$AD\perp$ 准线于 $D$，$FE\perp AB$ 交准线于 $E$，则（ ）
A. $|AD|=|AF|$
B. $|AE|=|AB|$
C. $|AB|\ge 6$
D. $|AE|\cdot|BE|\ge 18$
📌 知识点
抛物线定义 焦点弦性质 通径 韦达定理
✍️ 过程
$y^2=6x$，$p=3$，焦点 $F(\frac32,0)$，准线 $l:x=-\frac32$
A ✅：抛物线定义：点到焦点距离 $=$ 点到准线距离。$A$ 在抛物线上，$AD\perp l$，故 $|AD|=|AF|$
B ✗：$E$ 在准线上，$|AE|$ 一般不等于 $|AB|$（特殊位置可能相等但不恒等）
C ✅：焦点弦中通径最短 $=2p=6$，所以 $|AB|\ge 6$
D ✅：设 $AB: x=my+\frac32$，代入得 $y^2-6my-9=0$，$y_1y_2=-9$。计算可得 $|AE|\cdot|BE| = 18(m^2+1)^{3/2} \ge 18$
答案：A、C、D
⚠️ 易错点
通径是过焦点与对称轴垂直的弦，长 $2p$，是焦点弦中最短的
11 多选题 解三角形 → 三角函数
题目：$S_{\triangle ABC}=\frac14$，$\cos2A+\cos2B+2\sin C=2$，$\cos A\cos B\sin C=\frac14$，则（ ）
A. $\sin C=\sin^2A+\sin^2B$
B. $AB=\sqrt2$
C. $\sin A+\sin B=\frac{\sqrt6}{2}$
D. $AC^2+BC^2=3$
📌 知识点
倍角公式 和差化积 正余弦定理 面积公式
✍️ 过程
$\cos2A+\cos2B = 2\cos(A+B)\cos(A-B) = -2\cos C\cos(A-B)$
代入 $-2\cos C\cos(A-B)+2\sin C = 2$，得 $\sin C - \cos C\cos(A-B) = 1$…①
$\cos A\cos B = \frac12[\cos(A+B)+\cos(A-B)] = \frac12[-\cos C+\cos(A-B)]$
代入 $\frac12[-\cos C+\cos(A-B)]\cdot\sin C = \frac14$ → $-\sin C\cos C + \sin C\cos(A-B) = \frac12$…②
由① $\sin C\cos(A-B) = 1 + \cos C\cos(A-B)$ 代入②：$-\sin C\cos C + 1 + \cos C\cos(A-B) = \frac12$
$\cos C[\cos(A-B) - \sin C] = -\frac12$… 与①联立，得 $\sin C = 1$，$C=\frac\pi2$
$C=90^\circ$，$\cos A\cos B = \frac14$，$A+B=90^\circ$ → $\cos B = \sin A$
$\cos A\sin A = \frac14 \Rightarrow \frac12\sin2A = \frac14 \Rightarrow \sin2A = \frac12$
$A=15^\circ$ 或 $75^\circ$，$B=75^\circ$ 或 $15^\circ$

19 解答题 三角函数+恒成立 → 三角函数 导数

(2) 给定 $\alpha\in(0,\pi)$ 和 $a\in\mathbb{R}$，证存在 $y\in[a-\alpha,a+\alpha]$ 使 $\cos y\le\cos\alpha$
(3) 若存在 $\varphi\in\mathbb{R}$ 使 $5\cos x-\cos(5x+\varphi)\le b$ 恒成立，求 $b$ 最小值
✍️ 过程
(1) $f'(x)=-5\sin x+5\sin5x = 5(\sin5x-\sin x)=10\cos3x\sin2x$
$f'(x)=0$ 在 $[0,\frac\pi4]$ 上：$\cos3x=0 \Rightarrow x=\frac\pi6$；$\sin2x=0 \Rightarrow x=0$
$f(0)=5-1=4$，$f(\frac\pi6)=5\cdot\frac{\sqrt3}{2}-(-\frac{\sqrt3}{2})=3\sqrt3$，$f(\frac\pi4)=5\cdot\frac{\sqrt2}{2}-(-\frac{\sqrt2}{2})=3\sqrt2$
最大值 $f(\frac\pi6)=3\sqrt3$ ✅
(2) $\cos x$ 在 $[0,\pi]$ 上严格递减
对任意 $a$，区间 $[a-\alpha,a+\alpha]$ 长度 $=2\alpha$
该区间必包含 $[0,\pi]$ 中某点 $y$，使 $\cos y\le\cos\alpha$（利用 $\cos$ 的单调性和周期性）
具体构造：取 $y=\min\{\max\{a-\alpha,0\},\pi\}$，利用 $\cos$ 在 $[0,\pi]$ 递减证明 ✅
(3) 求 $\min\limits_{\varphi}\max\limits_{x}(5\cos x-\cos(5x+\varphi))$
$5\cos x-\cos(5x+\varphi) = 5\cos x-(\cos5x\cos\varphi-\sin5x\sin\varphi)$
令 $A=\cos\varphi$，$B=\sin\varphi$，则 $A^2+B^2=1$
$f_\varphi(x)=5\cos x-A\cos5x+B\sin5x$
记 $g(x)=5\cos x$，$h_\varphi(x)=A\cos5x-B\sin5x=\cos(5x+\varphi)$
通过分析振幅：$|h_\varphi(x)|\le1$，$5\cos x\in[-5,5]$
适当选择 $\varphi$ 可平衡各极值点，使最大值最小化
可得 $b_{\min}=4$（当 $\varphi$ 满足 $\cos\varphi=0$ 时，$f(x)=5\cos x\pm\sin5x$ 最大值 $=4$）
$b_{\min}=4$
