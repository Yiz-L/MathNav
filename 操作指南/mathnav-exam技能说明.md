# MathNav · 做题技能

> 调用方式：`/run mathnav-exam`
>
> 用户说"做一套新卷子"时，按此技能流程执行。
> 放在 `操作指南/` 下，每次新卷子复用。

---

## 🧠 技能名称：`mathnav-exam`

### 输入

用户提供：
- 试卷 PDF 路径 或 试卷文字内容
- 试卷名称（如 "2026新高考I卷"）

### 输出

- 新文件 `真题精讲/卷名.html`（全部N题精讲）
- 如有薄弱点 → 同步更新 `考点速查.html`
- 更新 `真题精讲/index.html` 列表
- 所有修改 git commit + push 部署

---

## 📋 执行步骤

### Step 1：获取试卷内容

用 `pypdf` 提取 PDF 文本，确认完整。

### Step 2：分析试卷结构

列出题型分布、每题考点。

### Step 3：创建精讲页面

按 [做题全流程.md](./做题全流程.md) 的 **② 创建真题精讲页面** 规范：
- 完整的 HTML 骨架（含 KaTeX CDN）
- 侧边栏（包含薄弱点区 + 题目锚点跳转）
- 进度总览表格
- 每道题按规范精讲

### Step 4：逐题精讲（核心）

每道题严格包含：
1. **📌 知识点** — tag 标签 + 表格展开 + 关联考点速查锚点
2. **✍️ 解题过程** — 分 step 步骤
3. **✅ 答案** — answer-box 显眼展示
4. **⚠️ 教学易错点** — 学生常见错误

### Step 5：标记薄弱点

做题中发现不熟悉的知识点：
1. 在 `考点速查.html` 对应模块添加 `weak-badge` 按钮
2. 创建 `weakness-detail` 卡片（含对比表格、记忆技巧）
3. 更新侧边栏薄弱点列表

### Step 6：更新真题列表

修改 `真题精讲/index.html`，添加新卷子的卡片入口。

### Step 7：部署上线

```bash
cd d:/Desk/MathNote/MathNav
git add .
git commit -m "完成[卷名]全部N题精讲"
git push
```

---

## 🔁 复用方式

下次用户说"做一套新卷子"，直接按此技能走 Step 1→7。

每道题写完问用户是否要继续下一题，保持交互节奏。
