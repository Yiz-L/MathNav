## ① 获取试卷内容

用户提供 PDF 路径后，提取文本：

```bash
# 用 pypdf 提取
python -c "
from pypdf import PdfReader
import sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8', errors='replace')
reader = PdfReader('路径/试卷.pdf')
for i, page in enumerate(reader.pages):
    print(f'=== 第{i+1}页 ===')
    print(page.extract_text())
    print()
"
```

提取后确认内容完整，逐题列出考点。

## ② 创建真题精讲页面

### 2.1 新建 HTML 文件

在 `MathNav/真题精讲/` 下创建 `卷名.html`

### 2.2 文件结构模板

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>卷名 — MathNav</title>
  <link rel="stylesheet" href="../assets/main.css">
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/katex@0.16.11/dist/katex.min.css">
  <script defer src="https://cdn.jsdelivr.net/npm/katex@0.16.11/dist/katex.min.js"></script>
  <script defer src="https://cdn.jsdelivr.net/npm/katex@0.16.11/dist/contrib/auto-render.min.js"
    onload="renderMathInElement(document.body, {
      delimiters: [
        {left: '$$', right: '$$', display: true},
        {left: '$', right: '$', display: false}
      ],
      throwOnError: false
    });"></script>
</head>
<body>
  <!-- 侧边栏 -->
  <!-- 主内容 -->
</body>
</html>
```

### 2.3 侧边栏结构

- **侧边栏标题**：`MathNav`
- **副标题**：`卷名 · 逐题精讲`
- **薄弱点区**：本卷发现的薄弱点列出
- **导航区**：首页、考点速查、真题列表
- **题目跳转区**：每道题 `#q1` `#q2` ... 锚点

### 2.4 主内容区结构

```
进度总览 Table（题号 | 题型 | 考点 | 答案 | 状态）

逐题卡片 .q-card
├── .q-header（题号+题型+标题+考点链接）
└── .q-body
    ├── .q-text（题目原文+选项）
    ├── 📌 知识点（tag标签 + 表格详细展开）
    ├── ✍️ 解题过程（step分步）
    ├── ✅ 答案（answer-box）
    └── ⚠️ 教学易错点（mistake-item）
```

## ③ 逐题精讲规范

每道题必须包含以下 **4个部分**：

### 3.1 📌 知识点
- 用 `tag` 标签列出本题涉及的考点
- 核心公式用表格展开
- 关联 `考点速查.html#module-X` 锚点跳转

### 3.2 ✍️ 解题过程
- 分步骤 `step` 呈现
- 公式用 `$...$`（行内）或 `$$...$$`（块级）
- 关键变形步骤写清楚

### 3.3 ✅ 答案
- `answer-box` 框显眼展示
- 单选题写字母，多选写字母组合

### 3.4 ⚠️ 教学易错点
- 学生最可能犯的 1-3 个错误
- 用 `mistake-item` 列表
- 有公式混淆的链接到 `考点速查.html#weak-xxx`

## ④ 发现薄弱点 → 更新考点速查

做题中发现不熟悉的知识点，同步更新 `考点速查.html`：

### 4.1 在对应模块下添加 `weak-badge` 按钮

```html
<button class="weak-badge" onclick="showWeakness('weak-xxx', this)">⚠️ 不熟悉</button>
```

### 4.2 创建薄弱详情 `weakness-detail` 卡片

```html
<div class="weakness-detail" id="weak-xxx">
  <button class="close-btn" onclick="closeWeakness('weak-xxx')">✕</button>
  <h3>🔴 标题</h3>
  <p>来源：<b>题目名</b></p>
  <div class="info-box">📌 一句话记...</div>
  <table>对比表格...</table>
  <ul>记忆技巧...</ul>
</div>
```

### 4.3 更新侧边栏薄弱点列表

```html
<button class="weakness-item" data-target="weak-xxx">
  <span class="tag">高</span> 名称
</button>
```

## 📐 KaTeX 公式注意事项

| 场景 | 写法 | 说明 |
|------|------|------|
| 行内公式 | `$a^2+b^2=c^2$` | 单个 $ 包裹 |
| 块级公式 | `$$...$$` | 独占一行 |
| 表格内公式 | `$...$` 正常使用 | 注意 `|` 不会冲突（HTML 中） |
| 花括号 | `\{x\mid x>0\}` | 需要反斜杠转义 |
| 竖线 | `\mid` 或 `\vert` | 避免歧义 |
| 下划线 | `\_` 在文本中 | 数学模式内 `_` 正常使用 |
| 空格 | `\quad` 在数学模式内 | 文本中用 `&nbsp;` |
| 希腊字母 | `\alpha \beta \pi` | 标准 LaTeX |
| 矩阵 | `\begin{matrix}...\end{matrix}` | KaTeX 支持 |
| 方程组 | `\begin{cases}...\end{cases}` | 常用 |
| 洛必达 | 不要写成 "洛" | 都用标准数学符号 |
