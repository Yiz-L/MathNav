# MathNav · 编辑指南

> 如何编辑 MathNav 网站的各个文件。

---

## ✏️ 编辑规范总则

1. **所有页面都是纯 HTML**，不需要服务器，浏览器直接打开
2. **公式用 KaTeX**：`$...$` 行内，`$$...$$` 块级，CDN 自动渲染
3. **颜色风格**：使用 `assets/main.css` 定义的 CSS 变量
4. **交互功能**：由 `assets/main.js` 提供（折叠/搜索/弹窗/打勾）

---

## 📄 各文件编辑要点

### 考点速查.html（考点库）

**知识点条目的格式：**
```html
<div class="topic" id="topic-xxx">
  <span class="checkbox" onclick="toggleCheck(this)"></span>
  <span class="text">知识点内容 $公式$</span>
  <button class="weak-badge" onclick="showWeakness('weak-xxx', this)">⚠️ 不熟悉</button>
</div>
```

**参数说明：**
| 属性 | 说明 |
|------|------|
| `id` | 唯一标识，锚点跳引用 |
| `checkbox` | 点击打勾 ✅ 标记已掌握 |
| `text` | 显示内容，支持 KaTeX |
| `weak-badge` | 薄弱点按钮，点开详情 |

**模块卡片的折叠：**
```html
<div class="module" id="module-X">
  <div class="module-header" onclick="toggleModule(this)">
    模块标题
    <span class="arrow open">▾</span>
  </div>
  <div class="module-body">
    <!-- 子标题 .sub-header -->
    <!-- 知识点 .topic -->
    <!-- 薄弱详情 .weakness-detail -->
  </div>
</div>
```

- `module-body` 加 `hidden` 类默认折叠
- `arrow` 加 `open` 类箭头朝上（展开状态）

**薄弱详情卡片结构：**
```html
<div class="weakness-detail" id="weak-xxx">
  <button class="close-btn" onclick="closeWeakness('weak-xxx')">✕</button>
  <h3>🔴 标题</h3>
  <p>来源说明</p>
  <div class="info-box">📌 记忆点</div>
  <table>对比表格</table>
  <ul>技巧列表</ul>
  <div class="source-link">关联题目</div>
</div>
```

**侧边栏薄弱点列表同步更新：**
```html
<button class="weakness-item" data-target="weak-xxx">
  <span class="tag">高</span> 名称
</button>
```

**二级标题（子模块）格式：**
```html
<div class="sub-header">4.1 函数概念</div>
```

### 真题精讲/xxx.html（真题页面）

**进度总览表格：**
```html
<tr><td>题号</td><td>题型</td><td>考点</td><td>答案</td>
<td style="color:#2ed573;">✅</td></tr>
```

**颜色含义：**
| 色值 | 含义 |
|------|------|
| `#2ed573` ✅ | 已做完 |
| `#ffa502` ⬜ | 待做 |
| `#ff4757` ⚠️ | 薄弱点 |

**题号圆标类型：**
```html
<span class="q-num">1</span>       <!-- 单选/多选/填空/解答，自动蓝 -->
<span class="q-num multi">9</span> <!-- 多选题 紫色 -->
<span class="q-num fill">12</span> <!-- 填空题 绿色 -->
<span class="q-num solve">15</span> <!-- 解答题 橙色 -->
```

## ⚡ JS 函数参考

定义在 `assets/main.js` 中：

| 函数 | 参数 | 说明 |
|------|------|------|
| `toggleModule(header)` | 模块标题 DOM | 折叠/展开模块 |
| `toggleCheck(el)` | checkbox DOM | 打勾/取消 |
| `showWeakness(id, btn)` | id 字符串, 按钮 DOM | 展开薄弱详情 |
| `closeWeakness(id)` | id 字符串 | 关闭薄弱详情 |
| `filterTopics()` | 无 | 搜索过滤知识点 |

## 🚫 常见编辑错误

| 错误 | 表现 | 解决 |
|------|------|------|
| `$` 没配对 | 公式显示为纯文本 | 检查 `$` 成对出现 |
| `\|` 在 `$` 外 | KaTeX 报错 | 改成 `\vert` 或 `\mid` |
| `{}` 没转义 | 渲染异常 | 用 `\{` `\}` |
| `id` 重复 | 锚点跳转失败 | 确保 `id` 唯一 |
| 拼错 `onclick` 函数名 | 点击没反应 | 检查控制台报错 |
| KaTeX CDN 加载失败 | 公式不渲染 | 检查网络，等 CDN 恢复 |
