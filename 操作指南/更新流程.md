# MathNav · 更新流程

> 当网站需要更新内容时，按此流程操作。

---

## 🔄 常规更新流程

### 第1步：修改本地文件

直接在 `MathNav/` 下编辑对应文件：

| 想更新什么 | 改哪个文件 |
|-----------|-----------|
| 做题进度 | `真题精讲/xxx.html` → 修改进度总览表格状态列 |
| 新增薄弱点 | `考点速查.html` → 添加 `weakness-detail` + 侧边栏 + 模块内按钮 |
| 首页进度 | `index.html` → 修改进度数字 |
| 真题列表 | `真题精讲/index.html` → 修改列表中的进度描述 |

### 第2步：提交并推送

```bash
cd d:/Desk/MathNote/MathNav

# 查看改了什么
git status

# 添加所有修改
git add .

# 提交（写清楚更新内容）
git commit -m "更新内容标题"

# 推送到 GitHub
git push
```

### 第3步：验证

等 1-2 分钟后打开：
https://yiz-l.github.io/MathNav/

确认更新已生效。

## 🆕 新增一套卷子的完整流程

```bash
# 1. 新建真题页面
touch "真题精讲/2026新高考I卷.html"

# 2. 按做题全流程.md 写完整精讲
#   - 进度总览 table
#   - 逐题卡片（知识点+过程+答案+易错点）
#   - 发现薄弱点同步更新考点速查.html

# 3. 更新真题列表
#   真题精讲/index.html → 添加新卡片

# 4. 提交推送
git add .
git commit -m "完成2026新高考I卷全部N题精讲"
git push
```

## ⚠️ 网络问题处理

如果 `git push` 报网络错误：

```bash
# 方法1：重试
git push

# 方法2：换用 SSH（如果配置了）
git remote set-url origin git@github.com:Yiz-L/MathNav.git
git push

# 方法3：用 gh CLI
gh repo sync Yiz-L/MathNav --branch main

# 方法4：等网络好了再推
# commit 在本地不丢失
```

本地 commit 是安全的，推不上去不会丢数据。
